Cendrillon

A guided desktop tool that takes a 3D scan all the way to printable molds for casting silicone — one step at a time.

What you’ll need

A 3D scan of the area you are casting for, as STL, OBJ, PLY, or 3MF. Cendrillon repairs and seals it for you, so a raw scan is fine.

You get back a set of .stl mold pieces — halves, plugs, and accessories — plus a written procedure.md covering the pour and demold. To use them you will need a 3D printer for the mold pieces and the casting silicone itself.

Running it

Cendrillon runs from source. You need a Rust toolchain — the pinned version is in rust-toolchain.toml — plus CMake and a C++ compiler, because the mold-CSG stage builds a vendored C++ kernel, and a working Vulkan or GL driver for the 3D views.

On Debian or Ubuntu, install the toolchain and libraries before you build. cmake, build-essential and pkg-config build the C++ kernel and locate system libraries; the rest are the workspace’s shared list, and without libfontconfig1-dev the build fails inside yeslogic-fontconfig-sys:

sudo apt-get update
sudo apt-get install cmake build-essential pkg-config \
  libwayland-dev libxkbcommon-dev libasound2-dev \
  libudev-dev libfontconfig1-dev

Then:

git clone https://github.com/via-balaena/CortenForge.git
cd CortenForge
cargo run --release -p cf-studio-gui

cf-studio-gui is Cendrillon under its internal name. The first build compiles its dependency graph — a large fraction of the workspace, including the C++ kernel — so expect it to take a while; after that it is incremental.

There are no prebuilt downloads. Building from source also means none of the unsigned-binary warnings macOS and Windows show for an unnotarized app.

What it does

A scan goes in; a set of printable mold pieces and a written fabrication procedure come out. Each step is guided; you can save the cleaned scan partway through, and export the printable files at the end.

It runs on CortenForge end to end — scan ingestion and repair, SDF conversion, multi-material layer stacks, mold splitting with registration features, printability gating, and generated pour-and-demold instructions. Everything it does is available as library calls if you would rather drive the same path from code.

Cendrillon’s workflow is built entirely from CortenForge components, and its whole source sits in the same repository — you can read every line before you run it.
